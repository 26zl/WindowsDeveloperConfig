# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the
existing issues before filing a new one to avoid duplicates:
<https://github.com/microsoft/WindowsDeveloperConfig/issues>.

When reporting a failing setup, include your Windows build (`winver`), the exact command
you ran, and the failing output. See [CONTRIBUTING.md](./CONTRIBUTING.md) for how to
propose changes.

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
